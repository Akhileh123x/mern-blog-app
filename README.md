# MERN Blog App

A full-stack blog application built using MongoDB, Express, React, and Node.js.

## Features
- Create, edit, delete blogs
- Authentication (if added)
- Responsive UI

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB

## Run Locally

### Client
cd client
npm install
npm run dev

### Server
cd server
npm install
npm start
